# Papers - 论文分析记录

> 本文件夹存放论文分析报告，由 AD-* 系列技能生成。
>
> 框架性知识（技术演进、技术路线、显存估算）已迁移至 `../` 根目录。

---

## 文件结构

```
papers/
├── README.md                              ← 本文件
├── survey.md                              ← 批量调研统计数据（AD-Literature-Evolution-Survey 生成）
├── [年份]_[会议]_[模型名称]_[核心任务].md  ← 单篇论文分析（AD-Single-Paper-Technical-Audit 生成）
└── ...
```

---

## 文件命名规范

### 单篇论文分析

**格式**：`[年份]_[会议]_[模型名称]_[核心任务].md`

**示例**：
- `2025_NeurIPS_AutoVLA_Planning.md`
- `2025_Tutorial_VLA4AD_QuickStart_Planning.md`
- `2026_arXiv_WA-JEPA_Planning.md`

**字段说明**：
- `年份`：论文发表年份
- `会议`：发表会议/期刊缩写（ICRA/CVPR/ECCV/NeurIPS/ICLR/arXiv/Tutorial 等）
- `模型名称`：论文提出的主要模型名称
- `核心任务`：主要任务类型（Planning/Perception/VLA/Generation/VQA 等）

### 批量调研记录

**文件**：`survey.md`（固定名称，仅保留统计数据与论文列表）

---

## 内容格式

所有分析报告遵循 `../AD_论文分析模板.md` 中定义的标准格式。

主要包含：
1. 模型组件
2. 参数状态
3. 微调方法
4. 训练范式
5. 技术定位
6. 任务与数据集
7. 复现信息

| 技能 | 输入 | 输出 | 说明 |
