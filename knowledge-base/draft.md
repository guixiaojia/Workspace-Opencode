## 实例回收规则

| 平台 | 回收规则 | 数据保留 |

**决策树**：

```
你要复现什么项目？
├── VLA4AD（OpenVLA、UniAD等）
│   └── Python 3.10 + CUDA 12.4 + PyTorch 2.2.0
├── VLM4AD（LMDrive、BEVFormer等）
│   └── Python 3.8 + CUDA 11.3 + PyTorch 1.12.1
```

**关键原则**：
1. **先看项目README**：优先使用项目官方推荐的版本组合
2. **版本锁定**：精确指定numpy、mmcv等关键库的版本号
3. **环境隔离**：每个项目使用独立的conda环境
4. **避免升级**：运行成功后不要随意升级依赖包
